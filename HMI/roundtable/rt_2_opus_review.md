## 2. 建議項目

### 2.1 減少 GUI 次數
1. **不要「全部刪光」**。z-order 用 Arrange 的「Send to Back／移到最後面」就能處理，不是重建的理由。
   - 已有正確位址與動作的零件，直接改樣式，可以少打位址，也少位址錯誤。這類零件有：
     - 啟動、停止、復歸、靜音、M2050、換頁鈕
     - 手動頁 7 顆
     - D300～D306、D210～D521 輸入
   - 只刪掉要換類型的零件，例如舊的 TABLE 顯示、多餘的文字。
   - 預估可省 20～30%。
   - 但要先在 spike 確認：改 Shape 之後，舊零件的 3D 樣式會完全清除。
2. **日期、時間的分隔字元合併成一個 Text**。Standard Font 是等寬字，可以把 `  /     :  :  ` 這樣的字串整條放在 Numeric 底下。
   - 自動頁：3 個 Text 變 1 個。
   - 中控頁：12 個變 3 個。
3. **先確認 Data Display 本身能不能帶 Shape（填色＋框）**。如果可以，白框、藍框的 Rectangle 都不用另外畫：
   - 自動頁省約 6 個
   - 中控頁省約 6 個
4. 中控頁的時間組做好一組（6 個 Numeric＋1 個 Text）後，整組複製。複製後用 GP-Pro EX 的位址搜尋取代（Edit／Utility 的 Search & Replace Address）把 D7024 換成 D7110、D7116。功能能不能用要在 spike 先試；不行就逐一改。
5. 殼層只有 3 個矩形，**不要用 Base Screen**。複製貼上就好（Q4）。

### 2.2 字型 spike 要加測的項目
- Standard Font 的 **Display Style 是否有 Bold**。GP-Pro EX 的 Text／Label 通常有 Standard/Bold/Shadow。如果有，F16 Bold 會比 F16 一般體更接近 prototype 的黑體。提案說「無粗體」並沒有驗證過。
- 字級的優先順序（Q3）：
  1. Image Font 20～24px（只用在靜態標題、按鈕）
  2. Standard 24（如果清單有）
  3. Standard 16 Bold
- **不要用 32**。prototype 主按鈕字約 20px，標題約 23px，32 會擠爆 110×60 的按鈕。

### 2.3 漏掉的元素與設定
- **Switch 的 Interlock**：prototype 與 SOP 寫明「停止中才有效」的 Switch，要設成 M200（自動運轉中）OFF 才能按：
  - M2050 Remote/Local
  - TABLE 1～3（D200）
  - 清零（PLC 已有 NOT M200，HMI 再擋一次比較保險）
- **A74 Remote/Local 切換鈕**應該帶 Lamp 狀態（依 M2050）。可以同色，但文字要分 ON「Remote 選擇中」與 OFF「Local 選擇中」。否則操作員看不出來自己選了什麼。M2051 是實際模式，M2050 是選擇值，兩者會不同。
- 警報頁的 Alarm History 需要在 Common Settings 的警報區塊中啟用 History，M140～M154 都要登錄（M151 已不使用，可以略過）。提案只寫「沿用」，要在前置截圖時確認。
- IO 表裡有 HMI 用的模擬位元（M51、M52、M53、M56、M57、M2065、M2070、M2071），但目前的畫面和提案都沒有放。依 SOP，這些位元由 GX Works3 Watch 操作，這次**不放**，記錄為「刻意不做」。
- 日期時間 A04/A05 讀的是 HMI 自己的時鐘，和 PLC 時鐘（中控會校時）無關。建議在系統設定看有沒有「從 PLC 同步時間」。沒有的話列入風險。
- A23 結束時間的 Numeric 要設定補零（Zero Suppress OFF）。

### 2.4 驗收
- 比對容許 ΔRGB ≤ 12 太鬆，例如 BL 偏 11 也能過關。改成**色票必須逐值相等**（GP-Pro EX 可以輸入 RGB），截圖比對只檢查位置。
- 如果機器上沒有 Python，比對腳本可以改用 PowerShell 的 System.Drawing（本次量測就是這樣做的）。
- 多加三個實機項目：
  - 字串位元組順序
  - HMI 時鐘
  - Interlock

## 5. 風險清單補充
13. 字串位元組順序（LH/HL）設錯，序號、工單會亂碼。模擬器看不出來，**必須接中控實機驗收**。
14. Lamp 的「ON 時透明／無形狀」如果不支援，L10b 結果遮罩要改用備案。
15. SOP 的 C5、D5（「治具夾好不亮」）、3.1 導覽表，和新的紅綠語意不一致，HMI 完成後要同步修 SOP。
16. HMI 時鐘和 PLC、中控的時鐘不同步，頁首時間和結束時間可能差幾秒到幾分鐘。
17. 改用舊零件時，舊的 3D 樣式或 Stroke Font 可能殘留在某個 State（ON/OFF 分開設定）。每顆都要檢查兩個狀態。
18. M0、M2113 是 PLC 內部位元，HMI 讀取不需要改 PLC，但要在 GP-Pro EX 確認 SLMP 讀得到 M0（M 範圍設定）。
19. 右面板 R2～R8 的列距只有 28～30px，F24 的總數字會頂到框緣。如果 spike 顯示太擠，總數改用 F16，並把標籤加粗。

# HMI 重做提案（提案方：Sonnet 5.5）

專案：ScrewMachine_HMI_v3_1.prxe，800×480，GP-Pro EX 4.09 SP2。所有座標為 800×480 實機座標（prototype 量測值 ÷2，四捨五入到整數；量測誤差約 ±1px）。

## 0. 結論先講

1. 問題根源有三個：Stroke Font、預設 3D 按鈕、沒有分區面板。換成「平面色塊 + Standard Font + 面板分區」就能達到 85～90% 相似。
2. 做不到的是：字型反鋸齒、粗體、圓角、框線 1.5px 的細節。這些我老實列在第 7 節。
3. 建議策略：全部砍掉重建（不是逐一改舊零件），因為 z-order（面板必須在最底）。先花一個「樣板頁」做 5 個樣板零件，再複製改位址。
4. 先做自動頁，驗收通過再做其他頁。若時間不夠，自動頁 + 中控頁就是使用者最在意的兩頁。

## 2. 字型與框線

### 2.1 字型規則
prototype 實測字寬（實機 px）：標題 ≈23、主按鈕（啟動／停止／復歸／數量狀態標題／螺絲）≈20、其餘中文 ≈13～17、數字 ≈ 8x16 等寬。

- 全部改用 **Standard Font，語系 Chinese(Traditional)**（實心黑體，字寬固定）。
- 規格只用三級（需在 spike 時確認對話框實際提供的尺寸，若清單沒有 24，退到 16 的 1×2 倍高或 32 的縮小版）：
  - **F16**：標籤、數值、狀態字、小按鈕、面板標題。佔 90% 的零件。
  - **F24**：頁面標題（第 2、3、4 頁的標題也用）、啟動／停止／復歸、「數量狀態」「螺絲 TABLE」標題。
  - F32：不使用（prototype 沒有 32 的字）。
- 數字顯示（Numeric Display）：Standard Font 8×16（F16 的 ASCII），右對齊，補零依各欄位。
- 兩行標籤（蜂鳴器靜音、手動頁面…）：Label 內換行，F16。
- 備案（spike 驗證後才採用）：若 GP-Pro EX 在 Switch Label／Text 提供 Image Font（Windows 字型，可抗鋸齒、可選 14/20px），則**僅靜態文字**改用 Image Font（微軟正黑體），動態數字仍用 Standard。能更接近 prototype，但要先驗證是否能用在 Switch 標籤。

### 2.2 框線與形狀
- 面板：Rectangle，填 PN，框 PB 1px，直角（prototype 圓角約 2～3px，忽略）。
- 輸入／顯示框：框 IB 1px，填 WH（或 CR）。
- 按鈕與燈號：Switch/Lamp，Shape 選最平的樣式（在 spike 中挑，目標為「Plain／Flat 矩形」），框 BD 2px。不要用預設凸起 3D 樣式。
- 外框：整頁一個無填色 Rectangle，框 FR 2px。
- 標題列：Rectangle X0,Y0,W800,H44，填 TB；下方 Rectangle X0,Y44,W800,H2，填 TL。

## 7. 施工順序與策略

### 7.1 前置（約 10 個動作）
1. 確認 git 乾淨，在 968d013 之後開分支 `hmi-redo-v4`。
2. 另存 .prxe 備份（不要 Write 到實機）。
3. 把現有每個零件的位址（尤其警報、訊息表、換頁目的、輸入的位數／小數）截圖存檔。簡報位址表已大致覆蓋；手動頁 M103～M115 對應要靠這一步確認。

### 7.2 Spike（先做、最重要，約 40 個動作）
在 Screen 1 做一顆測試用 Switch 與一顆 Lamp，確認：
1. Standard Font 的可選尺寸清單（是否有 16×16、24×24；有無倍率）。
2. 最平的 Shape 是哪一種、框線能否 2px、能否設閃爍。
3. Word Lamp（D2050，6 狀態）與 Switch 依 D200 變色是否可行。
4. Image Font 是否能用於 Switch 標籤（備案）。
5. Numeric Display 透明底（疊在 Rectangle 上）可行。
結果決定第 2.1 節的備案要不要採用。

### 7.3 建立順序（每頁相同）
1. 刪光舊零件（拖框全選 Delete；全頁一次）。不逐一修改，因為舊零件 z-order 在面板之上、樣式也要全換。
2. 設畫面背景色 BG；放共用殼層（優先 Base Screen）。
3. 先畫所有面板 Rectangle（它們自然位於最底）。
4. 樣板零件各做一次，再複製：
   - 樣板 T1：標籤 Text（F16，字 TX）。
   - 樣板 T2：數值藍框 Numeric Display（BL／WH／F16）。
   - 樣板 T3：白底字串／數值顯示框（WH／IB）。
   - 樣板 T4：Bit Lamp（GY→G2，F16，框 GB 2px）。
   - 樣板 T5：Switch（BR／WH／F16，框 BD 2px）。
   複製貼上（先點畫布），方向鍵微調，再於屬性面板輸入精確 X／Y／W／H、位址、文字。多選改 X/Y 的雷：永遠逐一改。
5. 放置順序：標籤 → 顯示框 → 數值／字串 → 燈號 → 按鈕 → 換頁。
6. 每完成一個區塊就存檔、截圖（防止當機損失）。

### 7.4 頁面優先序與估時
零件量估計：自動頁約 75 個、中控頁約 90 個、手動頁約 18 個、警報頁約 15 個，合計約 200 個。以 5～15 動作計，約 1500 個 GUI 動作。優先序：自動頁 → 中控頁 → 手動頁 → 警報頁。每頁之後立即模擬器驗收，不通過不往下。

## 8. 驗收方式

### 8.1 並排比對
1. 模擬器截圖存成 800×480。把 prototype 縮成 800×480（兩張 PNG ÷2）。
2. 做三種比對：並排、50% 疊圖、差異圖（用 Python Pillow 的 ImageChops 在本機腳本做，不修改專案）。
3. 位置容許誤差 ±2px；顏色容許 ΔRGB ≤ 12；文字內容 100% 一致（紅色註解不得出現）。

### 8.2 自動頁檢查點
- 無點陣格、無灰底、無 3D 黑框。
- 標題列、3 個面板、警告橫幅、底部列、TABLE 面板都在位。
- 所有按鈕字型為 Standard Font，不是細線字。
- 無任何紅色註解字樣（D7001、M2051…）。
- 模擬器手動改值（可在模擬器內設定位元）驗證：D2050 切 0～5 的 6 種狀態字與顏色；M2052 ON 紅閃；M2111/M2112 的 OK／NG／空白；D200=1/2/3 黃色換位；M2051 切 Local／Remote。
- 換頁鈕全部跳對頁。

### 8.3 其他頁
- 中控頁：兩個面板、所有藍框數字、B01～B15 燈 ON/OFF 顏色、M2052 紅閃。
- 手動頁、警報頁：與自動頁同色語言，按鈕不重疊、字不超出框。
- 全部頁面：字不被截斷（尤其「Remote / Local 切換」「RC75 RETURN」「Ready資料」）。

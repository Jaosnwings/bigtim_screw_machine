## 執行方式的限制（很重要，計畫必須符合）
- **只能用電腦操作（滑鼠、鍵盤）控制 GP-Pro EX 4.09 SP2**。.prxe 是專有格式，不能直接編輯檔案。
- 每個零件大約要 5～15 次 GUI 動作。
- 已確認可行的操作：
  - 在屬性面板逐一改 X/Y/寬/高、位址、文字、常數。
  - 複製貼上單一零件或一組零件，再用方向鍵 1px 微調。
  - 雙擊零件開設定對話框，可設定 Shape、顏色、Label 字型（Stroke Font 或 Standard Font）與字級。
  - Draw 選單可以畫填色矩形（Rectangle），可設填色、框線色、圓角。
- 已知的雷：
  - 多選後在屬性面板改 X/Y，會把**每個**零件都設成同一個值（會疊在一起），只能逐一改或用方向鍵。
  - Ctrl 或 Shift 點選無法加選，只能拖框選取。
  - 貼上前必須先點畫布。
  - 對話框位置不固定，要先截圖再點。
- 模擬器：
  - 不接 PLC，數值都是 0。
  - 不能 Write 到實機 PLC 或 HMI。
- 字型：
  - Standard Font 可以選 Chinese(Traditional)，也比較接近 prototype 的實心黑體字。
  - 目前用的是 Stroke Font，所以看起來很細很醜。
  - 請評估 Standard Font 能選的尺寸（例如 8×16、16×16、大小倍率）是否能做到 prototype 的效果。
- 顏色：GP-Pro EX 可以用 RGB 自訂色或 256 色盤。

## 會議要產出的東西
一份可以照著執行的計畫，內容包含：
1. 視覺規格：
   - 色票（背景、面板、按鈕、狀態色；請從 prototype 取近似 RGB）。
   - 字型與字級。
   - 框線樣式。
2. 每一頁每個元素的精確座標（以 800×480 計，等於 prototype 座標 ÷2）、大小、零件類型、位址、各狀態的顏色與文字。
3. 施工順序與策略：
   - 例如先刪除舊零件再重建，或先做一個「樣板零件」再複製改位址，以減少 GUI 次數與風險。
4. 驗收方式：
   - 例如模擬器截圖與 prototype 並排比對，列出檢查點。
5. 風險與取捨：
   - GP-Pro EX 做不到「一模一樣」的地方要老實列出，並提出最接近的做法。

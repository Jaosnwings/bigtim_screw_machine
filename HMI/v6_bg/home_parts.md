### D2053 下一步碼（建議 PLC 在 P70 算，一個掃描一次）

```
IF NOT M200 THEN D2053 := 100 + D2052;          (* 停止中：缺什麼條件 *)
ELSIF M2051 AND NOT M2400 THEN D2053 := 31;      (* Remote 且沒刷工號 *)
ELSIF NOT M2062 THEN D2053 := 32;                (* 靜電不 OK *)
ELSIF M2111 AND (D100 = 10) THEN                (* 本件結果剛出來 *)
    IF M2112 THEN D2053 := 41; ELSE D2053 := 40; END_IF;
ELSE D2053 := 20 + D2051;                        (* 運轉中：等待條件 *)
END_IF;
```

## 「更多」切到哪裡（建議）

把現在的 Base 1（v5 自動頁，含系統訊息、interlock 燈、警告橫幅、蜂鳴器靜音 M120、Remote/Local M2050、中控監視、警報參數、手動頁、TABLE D200、清零 M130、模式／步序／模擬）**整頁複製成 Base 6「詳細」**，新首頁放在 Base 1：

- 好處：舊頁所有功能原封不動保留，現場人員要看細節或維修時按「更多」就回到熟悉的畫面；手動頁、IO 頁不用改。
- Base 6 標題改「詳細／更多」，右上角「手動頁面」保留；再加一顆「回首頁」→ Base 1（放在 746,6 的位置，原「手動頁面」往左移，或用 642/722 兩顆按鈕其中之一）。
- Base 2、3、4 的「回自動頁面」仍回 Base 1（新首頁）。

## 現場接線與 I/O 表不符（使用者 16:20 告知）

- **Y5 現場接的是「機台啟動按鈕」，不是塔燈黃燈。** I/O 表與 v3.1 程式都把 Y5 當黃燈：
  `M405 := (NOT M200 AND NOT M203) OR (M204 AND SM412)`，警告時（M152 中控未接）每 0.5 s 閃爍。
  所以從 PLC 重開（約 15:3x）起，Y5 一直以 0.5 s 週期 ON/OFF 送到啟動按鈕那一路。
- 待確認：Y5 是啟動按鈕的「指示燈」，還是會送出「啟動訊號」給其他設備；塔燈黃燈實際接在哪一點。
- 影響：I/O 表、P40 的 M405、HMI/SOP 中「黃燈」的描述都要依實際接線修正。

### 待辦：之後寫進 PLC 程式（使用者 16:13 要求「先記錄，之後加到 PLC」，尚未修改）

目標：X0（急停 NC）由 OFF 回到 ON 的那一刻，Y3 輸出一次約 1 秒的脈衝，由 PLC 自己做（每次掃描就反應，不再靠 PC）。

草案（未套用，需確認 Y3 實際接的設備與脈衝長度）：

```
(* P40：X0 上升緣 → Y3 單發 1.0 秒（M940/M941 邊緣、D530 計時 0.1s） *)
M940 := M0 AND NOT M941;  M941 := M0;
IF M940 THEN M942 := TRUE; D530 := 0; END_IF;
IF M942 AND M950 THEN D530 := D530 + 1; END_IF;      (* M950 = P05 的 0.1 秒脈衝 *)
IF D530 >= 10 THEN M942 := FALSE; END_IF;
M403 := M942;
(* P70：Y3 := FALSE 改成 Y3 := M403; *)
```

待確認：Y3 現場接什麼、脈衝長度、模擬模式（M50）時是否也要輸出、急停期間是否要擋。
修改後依流程：模擬器測試 → 使用者同意 → 備份 PLC → 寫入 → 重開驗證。

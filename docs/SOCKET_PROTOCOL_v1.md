# 鎖螺絲站 Socket 協定 v1

設計：只換資料進出方式。中控把原本 Modbus 寫進 D7000～D7029 的內容整包放在 HO 訊框；PLC 把 D7100～D7151 的內容整包放在 ST 訊框。兩者都是「目前狀態」，每 1 秒送一次、內容變化時立刻送，不需要逐筆 ACK。條碼機由 PLC 控制：中控送 TG，PLC 觸發 SICK 後回 SC。

連線：中控是 TCP server（192.168.1.200:9500），PLC 是 client（Active open）。ASCII 0x20～0x7E。訊框結尾 CR LF，接收端看到 LF 視為一筆結束。格式 `型別;key=value;…`，順序固定、每個 value 長度固定（數字左補 0，字串右補空白）。

## PLC→中控

HI（連線後一次）：`HI;st=02;eq=MC-D002;ver=0314;proto=01`（st 2 碼、eq 8 碼右補空白、ver 4 碼、proto 2 碼）

ST：`ST;hb=00123;run=1;sw=C110;t0=20261112153001;t1=20261112153008;ct=00064;tq=00125;ang=00000720;tj=1;aj=1;hj=9;tt=00210;stop=0000;cs=1;n=2`

- hb 5 碼 = D7100（照回最後收到的中控心跳）
- run 1 碼 = D7105
- sw 4 碼 16 進位大寫 = D7107
- t0 14 碼 = D7110～7115（YYYYMMDDhhmmss，沒有就全 0）
- t1 14 碼 = D7116～7121
- ct 5 碼 = D7122
- tq 5 碼 = D7140
- ang 8 碼 = D7141 32 位元
- tj/aj/hj 各 1 碼 = D7143/7144/7145
- tt 5 碼 = D7146
- stop 4 碼 = D7147
- cs 1 碼 = D7148
- n 1 碼 = D222

SC（回覆 TG）：`SC;rid=00017;raw=<32 碼右補空白，讀不到填 NoRead>`

## 中控→PLC

HO：`HO;hb=00124;code=09;b=0013;sn=<20 碼>;wo=<12 碼>;op=<10 碼>;ts=20261112153002`（整筆固定 98 字元，不含 CR LF）

- hb 5 碼 → D7000
- code 2 碼 → D7001
- b 4 碼 16 進位 → D7002
- sn → D7003～7012
- wo → D7013～7018
- op → D7019～7023
- ts → D7024～7029（全 0 = 不校時，此時不要改 D7024～7029）

長度不對或開頭不是 `HO;` 整筆丟掉、錯誤次數 +1。

TG：`TG;rid=00017`　PLC 觸發 SICK，3 秒內回 SC 並照抄 rid。

## 附錄：PLC v3.14 實作說明（不屬協定原文）

- 欄位位置（0 起算，HO）：hb 6–10、code 17–18、b 22–25、sn 30–49、wo 54–65、op 70–79、ts 84–97。分隔字元的位置也會檢查；數字欄只收 `0`～`9`，b 只收 `0`～`9`、`A`～`F`（也收小寫）；字串欄只收 0x20～0x7E。任何一項不合，整筆丟掉、D7162 +1，D7000～D7029 都不動。
- hb 超過 65535 視為格式錯；32768～65535 以 16 位元無號值存入 D7000（ST 回送時照原值）。
- 字串欄寫進 D7003～D7023 時，每個字放 2 字元，位元組順序沿用 M2091（OFF：第 1 字元在高位元組；ON：在低位元組）。
- ST 的數字欄：負值送 0，超過位數送全 9。sw 為 D7107 的 16 位元無號值。
- 一行（LF 前）超過 120 字元整行丟掉、錯誤 +1；空行忽略；開頭 `TG;` 且長度 12 視為 TG，其他都算格式錯。
- PLC 讀 SICK 中時又收到 TG：忽略這筆（D7169 仍 +1），中控 3 秒沒收到 SC 請重送。
- PLC 端連線 5 秒沒收到 HO 就關閉，3 秒後重連；連上後先送 HI。
